# LaSOT tracker comparison

A static page comparing a multi-memory SAM 2.1 tracker with five SAM 2.1-based trackers (SAM 2.1, SAMURAI, HiM2SAM, DAM4SAM, SENTRY-D4S) on the 280 LaSOT test sequences, with side-by-side videos.

Live page: https://wang2895-source.github.io/lasot-tracker-comparison/

Video frames come from the LaSOT test set and are shown for research purposes only.
